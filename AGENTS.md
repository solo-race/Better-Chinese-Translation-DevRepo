=========================================================================================
# Project Rules to Abide By
=========================================================================================

### ALLOWED ACTIONS
- Write scripts that automate the file, text, string search process for difference comparison. The resulting scripts should be stored in `scripts`
- Edit config files ending with `.yaml`, `.json`, `.toml` etc. 
- Write code for new functions the user demands. 

### FORBIDDEN ACTIONS
- Edit the actual contents of the text files, unless specifically asked by the user. 
- Edit any multimedia files located in the project dev space, regardless of it being a raw design file, or video/image/audio output.
